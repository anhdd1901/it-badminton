# Kế hoạch 3/4: Giao diện, Server Action và avatar

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Dựng toàn bộ giao diện ANH EM IT (đăng nhập, Tuần này, Xếp hạng/ELO, Thống kê, Lịch sử, Tôi, Quản lý mem) trên lớp nghiệp vụ đã có, kèm Server Action, cookie phiên, upload avatar, CSP và các yêu cầu bảo mật ở spec 5.4.

**Architecture:** `src/server/` giữ nguyên vai trò (hàm dịch vụ nhận `db`, `Actor`, `now`, không import Next.js); kế hoạch này bổ sung vài hàm còn thiếu ở đó. Phần nối với Next.js nằm ở `src/app/_lib/` (đều `import "server-only"`): db dùng chung, đồng hồ, cookie phiên, `runAction`. Mỗi màn là Server Component đọc qua các hàm `get…View`; mọi thao tác ghi là Server Action trong `src/app/_actions/`, trả `ActionResult` và gọi `revalidatePath("/", "layout")`. Thành phần giao diện dùng chung ở `src/components/`, logic thuần cho giao diện (token màu, định dạng số, avatar chữ cái, đọc `searchParams`) ở `src/ui/` có test đơn vị.

**Tech Stack:** Next.js 16.4 (App Router, Server Actions, `proxy.ts`), React 19.3, Tailwind 4, shadcn/ui (CLI 4), lucide-react, sharp 0.35, `@vercel/blob` 2, Vitest 5 + Testing Library + jsdom, Playwright 1.64.

**Spec:** `docs/superpowers/specs/2026-10-10-badminton-club-app-design.md` (mục 4, 5 gồm 5.4, 6.4, 8, 8.1, 9, 10). Đọc kèm `GLOSSARY.md`, `CLAUDE.md`, `docs/backlog.md` và các export của `src/server/` (kế hoạch 2).

**Các kế hoạch tiếp theo:** 4 Vận hành (Neon, Vercel, sao lưu GitHub Actions, `pnpm db:restore`).
